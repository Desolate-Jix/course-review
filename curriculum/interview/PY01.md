## 本节必练

## Q1：list、tuple、dict、set怎样选择？

**中文参考回答：** list保存有序元素并支持修改；tuple是不可变序列，但内部引用的对象仍可能可变；dict用于键到值映射；set表示唯一元素集合。按用户统计金额适合dict，检查出现过的id适合set。先描述所需操作，再选择容器。

**英文回答提纲：** Choose a container based on the operations you need: ordered items, a fixed sequence, key-value lookup or uniqueness. A tuple is immutable, but objects inside it may still be mutable.

**继续追问：** 为什么按用户金额汇总不能只用set？

**追问要点：** set不能直接存“用户id对应的累计金额”这一映射；dict更符合操作需求。

**常见失分：** 不要把tuple不可变理解为其中任何嵌套对象都不会变化。

## Q2：函数的return位置为什么重要？如何处理空输入和类型？

**中文参考回答：** return会结束当前函数。把汇总函数的return放在循环内，会只处理前面一部分数据；放在循环外才能处理全部记录。空输入的返回值要由接口明确，例如金额汇总返回0。CSV中的数字可能是字符串，必须先解析和验证，不能直接按数值使用。

**英文回答提纲：** Return exits the function immediately. An accumulator should usually be returned after the loop. Define empty-input behavior and validate types before performing numeric operations.

**继续追问：** 第一条订单是pending、第二条是paid，错误return会怎样？

**追问要点：** 可能在处理第一条后就返回0，漏掉第二条；这是比大量随机数据更清晰的最小反例。

**常见失分：** 不要认为类型注解会自动校验所有运行时数据。

## 15分钟课堂使用方式

- 3分钟：关闭答案，回答一题。
- 5分钟：用本节数据/代码补例子，接受一轮追问或反例。
- 4分钟：核对遗漏和错误，修改自己的提纲。
- 3分钟：用英语复述核心答案；保留不会说的关键词。

不额外延长学习日。实作仍在原练习时段完成，本页口述不能取代SQL/代码与结果验证。
