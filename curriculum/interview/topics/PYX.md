# PYX｜Python语言机制与并发

阶段：C｜Python/后端专项。先修：PY01–PY03；并发题先学OS。

以Python 3为主；涉及GIL明确CPython构建方式，不能泛化到所有实现。

本页为可直接复习的题目、答案要点与追问边界；首次遇到概念，先读资料并完成例子。它不等同于已编写完整教科书讲义，也不代表已经掌握。题量随覆盖缺口增长，不设上限。

|题号|问题|参考答案要点|追问与边界|
|---|---|---|---|
|PYX-01|LEGB作用域与闭包是什么？|名称按局部、外层函数、全局、内置查找；闭包保留对外层绑定的访问。|循环生成函数为何可能都得到最后值？名称晚绑定；需显式绑定当次值等方式。|
|PYX-02|装饰器怎样工作？|以函数或其他可调用对象接收目标并返回包装或替代对象，可实现日志/计时/权限等横切功能。|为什么用functools.wraps？保留元信息；包装还需正确传参与返回/抛异常。|
|PYX-03|迭代器与生成器有什么区别？|迭代器提供逐项next协议；生成器通过yield保存执行状态，是构造迭代器的一种方式。|生成器可反复从头遍历吗？通常单次消费；要重新创建。|
|PYX-04|with如何保证资源清理？|上下文管理器通过进入退出协议管理资源，退出阶段可在异常路径执行清理；是否抑制异常由退出返回语义决定。|finally里return有什么风险？可能覆盖原返回或吞掉异常，应避免无意改变控制流。|
|PYX-05|类、实例、继承与组合怎么选择？|类定义行为与属性结构，实例承载状态；继承表达可替代关系，组合把行为委托给成员以降低耦合。|所有复用都该继承吗？不，组合通常更易隔离变化，但需结合接口设计。|
|PYX-06|实例方法、classmethod、staticmethod怎样区别？|分别隐式接收实例、类或没有隐式首参数；类方法常用于替代构造器，静态方法用于相关工具逻辑。|类属性放可变list有何风险？多个实例可能共享同一对象，意外串状态。|
|PYX-07|__eq__与__hash__需要什么约定？|相等对象必须有相同哈希；作为哈希键期间相关状态应稳定。定义相等行为时需考虑是否仍可哈希。|可变业务字段做键后又修改会怎样？可能无法按原方式查找，应使用稳定标识。|
|PYX-08|Python如何管理内存？|CPython常用引用计数并辅以循环垃圾回收；其他实现可能不同。释放对象不等于操作系统立刻看到同量内存下降。|循环引用一定永久泄漏吗？不是，回收器可处理许多循环，但仍需正确管理资源。|
|PYX-09|GIL是否意味着线程安全或无法并行？|启用GIL的CPython限制同时执行Python字节码，但I/O和部分扩展可释放GIL；free-threaded构建不同。GIL不保证复合业务操作原子性。|CPU密集任务怎么选？考虑进程、释放GIL的库或适用构建，并测量而非套口号。|
|PYX-10|async/await适合什么？|协程在等待点让出执行，适合大量可异步等待的I/O；CPU长计算与同步阻塞调用会阻塞事件循环。|函数写async就自动并行吗？不会，调度、等待对象与底层调用都重要。|
|PYX-11|线程池、进程池与异步怎样取舍？|线程常适配阻塞I/O，进程适合隔离与部分CPU任务，异步适合可协作I/O；有序列化、启动、连接数和取消成本。|可以无限创建任务吗？不，应有并发限制、超时、背压和错误处理。|
|PYX-12|类型注解、虚拟环境、依赖锁分别解决什么？|注解支持静态工具与接口表达，通常不自动运行时校验；环境隔离包，依赖锁固定可复现解析结果。|注解int能阻止请求传字符串吗？单靠Python注解不能，需框架/验证层。|

## 课堂验证

写一个计时装饰器保留返回值与异常；用生成器读取小数据；比较异步等待与在协程中同步阻塞的执行时间线。

**预期与判分：** 装饰器不能吞异常；生成器输出与列表版一致且按需消费；能解释阻塞影响，不以一次耗时宣称固定加速倍数。

**英文关键词：** closure, decorator, iterator, context manager, GIL, event loop。用“结论→机制→本例→边界”组织短答。
