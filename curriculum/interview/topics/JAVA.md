# JAVA｜Java后端：语言、集合、并发、JVM与Spring

阶段：C→D｜投Java岗位时启用。先修：ALG02、OS、ENG、API；基础Java语法。

Java算法题语言不自动决定求职方向。本专项完整列入覆盖地图，投Java后端时按分组分课学习；JDK示例以21为基线，Spring以项目锁定版本为准。

本页为可直接复习的题目、答案要点与追问边界；首次遇到概念，先读资料并完成例子。它不等同于已编写完整教科书讲义，也不代表已经掌握。题量随覆盖缺口增长，不设上限。

|题号|问题|参考答案要点|追问与边界|
|---|---|---|---|
|JAVA-01|Java值传递、==与equals怎样回答？|Java参数传递值，对象参数的值是引用；==比较基本值或引用身份，equals按类定义判断逻辑相等。|方法内重绑形参能改变调用者变量吗？不能，但可通过共享引用修改对象。|
|JAVA-02|equals与hashCode为何必须配套？|逻辑相等对象应有相同hashCode，反向不成立；哈希容器需结合两者找键。|键入Map后修改参与哈希字段会怎样？可能找不到原条目，应使用稳定键。|
|JAVA-03|String不可变、字符串池与StringBuilder怎样理解？|String内容不可变，有利于共享和键稳定；池复用特定字符串，构建大量可变拼接可考虑Builder。|所有字符串比较都能用==吗？不能，池化不能替代逻辑相等。|
|JAVA-04|基本类型、包装类与自动拆装箱有哪些坑？|包装类是对象，拆箱null会异常，缓存与身份比较不应替代数值比较；精确十进制业务需考虑BigDecimal。|new BigDecimal(double)为何可能意外？二进制浮点近似会被带入，应选符合业务来源的构造方式。|
|JAVA-05|泛型擦除、反射与异常体系是什么？|泛型多数类型信息在运行时擦除，反射可检查和调用运行时成员；checked与unchecked异常有不同编译约束。|反射等于无权限限制吗？不，模块和访问控制仍有边界；不要吞异常掩盖失败。|
|JAVA-06|ArrayList与LinkedList怎么比较？|ArrayList数组支持快速索引和摊还追加；LinkedList逐节点定位且有额外对象开销，已知位置的局部改链才便宜。|头插多就一定LinkedList最佳吗？还应考虑ArrayDeque等结构及实际访问模式。|
|JAVA-07|HashMap内部结构、扩容和树化怎样回答？|按JDK版本解释桶、冲突链/树以及容量装载阈值；扩容需重新分布，树化条件还涉及表容量，不能只背链长。|默认API保证内部阈值永久不变吗？不是，实现细节看锁定JDK源码，先讲机制再讲常量。|
|JAVA-08|HashMap、TreeMap、ConcurrentHashMap怎么选？|分别适合一般哈希查找、有序键操作与并发映射；HashMap本身不提供并发修改安全。|ConcurrentHashMap的get再put整体原子吗？不，应使用适当原子复合API并注意回调约束。|
|JAVA-09|fail-fast迭代器能保证并发安全吗？|fail-fast只是尽力发现不合规结构修改，不是同步协议；并发安全靠正确容器和同步策略。|没抛ConcurrentModificationException就安全了吗？不能据此推断。|
|JAVA-10|JMM、happens-before、volatile如何联系？|JMM定义跨线程可见性与顺序保证，happens-before表达相应关系；volatile读写提供特定可见性和排序约束。|volatile int的i++原子吗？不是，仍是复合读改写。|
|JAVA-11|synchronized、Lock与CAS有什么区别？|前两类机制可互斥保护临界区并建立同步关系；CAS条件更新适合部分原子操作，但重试与ABA等需分析。|无锁就一定更快吗？高竞争下自旋与重试可能昂贵。|
|JAVA-12|wait/sleep、线程状态与中断怎么区别？|wait需相应监视器并释放它等待，sleep暂停线程但不因此释放已持锁；中断是协作取消信号，需要正确处理。|捕获InterruptedException后直接忽略好吗？通常不，应传播、退出或恢复中断状态。|
|JAVA-13|线程池参数和拒绝策略怎样选择？|解释核心/最大线程数、队列、存活时间和拒绝策略如何影响排队与资源；结合CPU/I/O及下游容量测量。|无界队列风险？任务堆积、内存增长和尾延迟，不能仅靠最大线程数保护。|
|JAVA-14|ThreadLocal用途和泄漏风险是什么？|提供线程关联状态；线程池会复用线程，使用后应清理，避免值和上下文残留。|ThreadLocal能自动把请求上下文传到其他线程吗？不能假定，需明确传播机制。|
|JAVA-15|JVM运行时内存区域有哪些？|堆主要放对象，线程栈保存帧，另有方法区相关实现、程序计数器与本地调用等；规范与HotSpot实现术语要区分。|Metaspace等于Java堆吗？不是，不要混淆方法区抽象与具体实现。|
|JAVA-16|类加载、双亲委派和初始化如何联系？|加载、链接、初始化是不同阶段，典型委派优先向父加载器请求以减少核心类型冲突；也存在定制加载场景。|加载类就立刻执行所有静态初始化吗？不，应按主动使用等初始化规则判断。|
|JAVA-17|GC如何判定存活，常见收集方式怎么权衡？|从根追踪可达对象并按收集器策略回收；复制、标记清理、整理等方法在吞吐、停顿和内存间权衡。|引用计数能独立解决所有循环吗？不能；Java GC不能简单说成引用计数归零。|
|JAVA-18|OOM、高CPU与长GC怎样排查？|先区分堆/元空间/线程等资源，结合监控、线程栈、堆转储和GC日志形成假设，避免直接只加内存。|一次堆快照能证明泄漏吗？通常需看持续增长、引用链和业务生命周期。|
|JAVA-19|Spring IoC/DI、Bean生命周期与作用域是什么？|容器管理对象创建、依赖装配和初始化销毁；singleton等作用域定义实例管理范围。|单例Bean默认线程安全吗？不是，共享可变状态需同步或避免共享。|
|JAVA-20|AOP代理、自动配置与循环依赖怎样理解？|代理在调用边界插入横切逻辑；Boot按条件及配置组织自动配置；循环依赖反映耦合，是否可解依注入方式和版本。|自调用一定经过代理吗？典型代理模式下不会，不能假设所有内部调用都被增强。|
|JAVA-21|@Transactional为什么可能不生效？|可能未经过代理、对象非容器管理、事务管理器/方法可见性不符或异常处理不符合回滚规则；按实际版本和配置检查。|catch吞异常后一定回滚吗？不能，需看事务是否被标记回滚及策略，不凭注解名字推断。|
|JAVA-22|事务传播、隔离与Spring MVC请求流程如何区分？|传播决定方法调用如何参与事务，隔离决定并发可见性；MVC通过调度、映射、适配、参数校验与异常处理组织请求。|REQUIRES_NEW等于更高隔离吗？不是，它创建独立事务语义，还影响连接需求与提交边界。|
|JAVA-23|AQS与可重入锁怎样联系？|AQS提供同步状态和等待队列框架供特定同步器实现获取/释放语义；可重入允许同一线程重复获取并配对释放。|AQS本身等于某一种锁吗？不是，不同同步器定义不同状态规则。|
|JAVA-24|Future与CompletableFuture如何组织异步结果？|Future表示待完成结果，阻塞get可能等待；CompletableFuture支持阶段组合与异常处理，执行器选择影响资源。|异步链是否自动隔离CPU和I/O任务？不会，必须明确执行器与并发预算。|
|JAVA-25|BIO、NIO与零拷贝怎么理解？|阻塞I/O、通道缓冲区和选择器提供不同编程模型；零拷贝通常减少特定用户/内核数据复制，而非所有复制消失。|NIO一定更快吗？依并发规模、数据路径和实现复杂度，不能只背缩写。|
|JAVA-26|Stream与parallelStream有哪些边界？|Stream表达数据处理管道，惰性操作由终止操作驱动；并行流适合可分解且无不当共享状态的工作。|集合越大就一定并行快吗？拆分、合并、共享池竞争及阻塞调用都可能抵消收益。|
|JAVA-27|MyBatis的参数绑定与缓存有什么风险？|区分参数绑定与直接文本替换，后者用于动态结构时需白名单；缓存范围、事务和失效按配置说明。|动态ORDER BY能直接接用户文本吗？不能，应映射到允许的列与方向。|
|JAVA-28|Bean初始化销毁、构造器注入与循环依赖怎么验证？|用小例子记录创建、注入、初始化与关闭回调；构造器注入明确必需依赖，循环依赖优先重构职责。|单例指整个JVM绝对只有一个对象吗？通常是容器/定义范围，不应泛化成进程全局唯一。|

## 课堂验证

按语言集合→并发→JVM→Spring分四组课：写可变键反例；比较非原子与原子计数；读取课堂进程线程/GC信息；用集成测试比较经代理事务调用与自调用。

**预期与判分：** 能用实际JDK/框架版本解释现象；集合键失效与并发问题有最小复现；事务测试核对数据库实际状态。尚无Spring基础时先补教学再做，不能只背注解。

**英文关键词：** hash contract, happens-before, thread pool, garbage collection, dependency injection, transaction proxy。用“结论→机制→本例→边界”组织短答。
