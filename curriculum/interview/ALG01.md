## Q1：如何分析时间与空间复杂度？两个循环就是O(n²)吗？

**中文参考回答：** 先数操作随输入规模增长的总次数。两个顺序n次循环仍是O(n)；嵌套循环要看内层累计次数，不能只看层数。额外空间计算辅助结构，原地过滤仅几个下标通常是O(1)；另建长度n的列表就不是O(1)。

**英文回答提纲：** Count how work grows with input size. Two sequential linear loops are still O(n). For nested loops, count total iterations. Include auxiliary data structures when analysing extra space.

**继续追问：** 为什么快慢指针原地过滤可以是O(n)/O(1)？

**追问要点：** 每个元素扫描一次，write只前进，额外只用固定数量下标；即使再补零也只是一次线性扫描。

**常见失分：** 不要把O(n)说成运行n秒，也不要漏掉新建数组的空间。

## Q2：什么是循环不变量？如何解释Move Zeroes的正确性？

**中文参考回答：** 循环不变量是在循环各步维持的性质。稳定过滤中，[0,write)始终保存已读部分所有应保留元素且顺序不变。每次读一个非0就追加到该前缀，读完后补零，因此结果满足需求。还需说明写入位置不会覆盖未读数据。

**英文回答提纲：** A loop invariant describes what remains true during iteration. The prefix before write contains the retained values from the processed input in their original order.

**继续追问：** 面试中只有最终样例正确，够证明算法正确吗？

**追问要点：** 不够；还需解释为何每步保持性质、结束时得到目标，并检查空数组/全0等边界。

**常见失分：** 不要只说“这是双指针模板”，必须说清每个指针和区间的含义。

## 按知识点补充的必修问答

### Q3：数组和链表的访问与插入成本怎么比较？

**参考答案：** 数组按下标访问通常O(1)，中间插删需移动；链表定位通常O(n)，已知节点的局部改链可O(1)。

**追问与边界：** 链表插入一定更快吗？定位、分配与缓存局部性会影响实际成本。

**英文关键词：** random access, locality。

### Q4：稳定性、原地与时间复杂度是同一维度吗？

**参考答案：** 不是。稳定性保留相等键相对顺序，原地关注额外空间，复杂度描述规模增长。

**追问与边界：** 原地算法一定稳定吗？不，如常见交换式排序可不稳定。

**英文关键词：** stable, in-place。
