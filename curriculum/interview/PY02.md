## Q1：赋值、浅复制和深复制有什么区别？

**中文参考回答：** 赋值绑定对象引用，不复制对象。浅复制创建外层容器，但嵌套可变对象仍可能共享；深复制通常递归复制嵌套对象。对list[dict]只做list.copy，修改内部dict仍影响原数据。也可以设计函数产生新记录，避免不必要的就地修改。

**英文回答提纲：** Assignment shares a reference. A shallow copy duplicates the outer container but can share nested objects. A deep copy recursively copies contents; choose the level of isolation you actually need.

**继续追问：** 逐行dict.copy后，嵌套tags列表是否独立？

**追问要点：** 仍可能共享。修改复制行中的tags会影响原行，除非也复制该列表或采用其他隔离设计。

**常见失分：** 不要把浅复制说成完全独立，也不要所有场景都无条件deepcopy。

## Q2：为什么不建议用可变对象作默认参数？==和is有什么区别？

**中文参考回答：** 默认参数在函数定义时求值，默认列表可能被多次调用共享。常用None作默认值，在函数内新建列表。==比较值是否相等，is比较是否为同一对象；判断None可用is None，普通字符串或数字内容比较用==。

**英文回答提纲：** Mutable default arguments can be shared across calls. Use None and create a new object inside the function when needed. Equality compares values; identity checks whether references point to the same object.

**继续追问：** 两个内容相同但分别创建的列表，==和is可能分别是什么？

**追问要点：** ==为True，is为False；这说明内容相等不代表同一个对象。

**常见失分：** 不要根据某次字符串驻留结果把is当内容比较使用。

## 按知识点补充的必修问答

### Q3：函数参数到底传了什么？

**参考答案：** Python把实参对象绑定到形参名；改变可变对象可能被调用者看到，形参重新绑定通常不会改变外部名称绑定。

**追问与边界：** append与x = x + [1]对调用者影响一样吗？不一样，前者原地修改，后者新对象绑定。

**英文关键词：** object sharing, rebinding。

### Q4：复制二维列表怎样避免行共享？

**参考答案：** [[0]*3]*2复用了同一行对象；用列表推导式每次创建新行。浅复制外层也不会复制内层。

**追问与边界：** 怎样验证？修改第一行一格，确认第二行没变并比较对象身份。

**英文关键词：** aliasing, nested list。
