## 本节必练

每次从下面两题选一题：先30–60秒给直接答案，再用1–2分钟补机制、例子与边界，最后回答追问。第二次学习/复习换另一题，不能永远只练熟悉题。

## Q1：滑动窗口为什么能减少重复计算？

**中文参考回答：** 连续区间移动时保留可更新的状态。固定长度求和先计算首窗，右移减离开值、加进入值，避免对每个窗口重新求和。要明确窗口边界和状态含义，负数情况下最大值应从真实首窗初始化。

**英文回答提纲：** A sliding window reuses state as a contiguous range moves. For a fixed-size sum, subtract the outgoing value and add the incoming one instead of recomputing the entire window.

**继续追问：** 为什么最大和不能直接初始化为0？

**追问要点：** 全负数输入的真实最大和仍小于0，初始化0会报告不存在的更优结果。

**常见失分：** 不要把滑动窗口当成适用于所有子数组问题的通用模板。

## Q2：可变窗口里套while，为什么仍可能是O(n)？

**中文参考回答：** 如果左右指针只向前，每个元素最多进入窗口一次、离开一次，总移动次数O(n)。缩窗必须有明确的合法条件，例如最多k个0。分析重点是累计移动次数，不是代码缩进层数。

**英文回答提纲：** If both pointers only move forward, each element enters and leaves at most once. Total pointer movement is linear, even though the code contains a nested while loop.

**继续追问：** 包含负数的任意区间和条件都能这样缩窗吗？

**追问要点：** 不能直接套。需要检查条件是否具备适合的单调性；负数可能破坏扩张/收缩对和的单调影响。

**常见失分：** 不要只因用了两个指针就声称线性复杂度，要证明不会反复回退扫描。

## 15分钟课堂使用方式

- 3分钟：关闭答案，回答一题。
- 5分钟：用本节数据/代码补例子，接受一轮追问或反例。
- 4分钟：核对遗漏和错误，修改自己的提纲。
- 3分钟：用英语复述核心答案；保留不会说的关键词。

不额外延长学习日。实作仍在原练习时段完成，本页口述不能取代SQL/代码与结果验证。
