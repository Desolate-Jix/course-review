## 讲解与例题


### 1. 赋值不是复制对象

```python
a = [{'id': 1, 'amount': 100}]
b = a
b[0]['amount'] = 200
```

a和b指向同一个列表，因此a中的amount也变成200。`b=a.copy()`只复制外层列表，其中dict仍是共享对象，所以修改b[0]仍会影响a[0]。

如果dict中只有不可变标量字段，可以用 `[row.copy() for row in a]`复制每一行；若还有嵌套的可变列表或字典，需要进一步复制，或在设计上避免就地修改输入。不能把浅复制描述成“完全独立”。

### 2. 默认参数也可能共享

```python
def add_item(x, items=None):
    if items is None:
        items = []
    items.append(x)
    return items
```

把默认值写成 `items=[]`时，默认列表会跨调用复用。使用None并在函数内创建新列表可避免这个意外。这里用 `is None`检查是否为同一个None对象；普通数值/字符串内容比较用 `==`。

### 3. 调试先缩小反例

遇到结果错，先记录期望输出和实际输出，再把输入减到能复现的最小样例。逐步检查类型、循环边界、共享对象和过滤条件。不要同时改多个地方，否则难以知道原因。

类型注解有助于阅读，但通常不会自动在运行时验证输入。校验需要明确的代码或框架支持。
