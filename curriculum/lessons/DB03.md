先修：DB02。先修待验证时先做前节验收；通过可跳过重复讲解。

## 讲解与例题


### 1. 聚合把多行变成摘要

`SELECT SUM(amount) FROM orders`把5条订单合成一条汇总，结果450。没有GROUP BY且没有筛掉聚合结果时，整个输入作为一个组。GROUP BY则先按指定键分组，再每组计算一次。

```sql
SELECT user_id, COUNT(*) AS order_count, SUM(amount) AS total
FROM orders
GROUP BY user_id
ORDER BY user_id;
```

结果为 `(1,3,400),(2,1,50),(4,1,0)`。用户3不在orders里，聚合不会凭空创建这一组。此时输出一行的含义变成“一个有订单的用户”。

### 2. WHERE在分组前，HAVING在分组后

```sql
SELECT user_id, SUM(amount) AS paid_total
FROM orders
WHERE status='paid'
GROUP BY user_id
HAVING SUM(amount) >= 100;
```

先留下101、103、105，再分成用户1和2两个组，最后只保留总额200的用户1。不能用WHERE直接筛选本层的SUM，因为它还没有形成。

### 3. 数行与数非空值

`COUNT(*)`数行；`COUNT(city)`数city非空的行。users中分别为4和3。空输入上COUNT返回0；SUM通常返回NULL，业务确实把无记录理解为0时，可用COALESCE转换。

SQL初学阶段，把所有非聚合的输出列都明确写进GROUP BY，避免依赖特定数据库的函数依赖推断。不要利用SQLite允许的宽松分组取任意非分组列。
