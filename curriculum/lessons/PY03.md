## 讲解与例题


### 1. 在处理前定义规则

本练习使用 [dirty_orders.csv](../labs/dirty_orders.csv)。字段为id,user_id,amount,status；id/user_id/amount必须为整数，金额非负，用户必须存在，状态只能paid/pending/cancelled。以订单id识别重复：同id同内容归重复；同id不同内容归冲突拒绝。先校验一行合法，再判断它是否重复。

### 2. 区分可恢复数据错误和程序错误

```python
import csv
with open('orders.csv', newline='', encoding='utf-8') as f:
    for raw in csv.DictReader(f):
        try:
            amount = int(raw['amount'])
        except (ValueError, TypeError):
            # 记录该行及原因，继续处理其他行
            continue
```

示例只展示解析金额这个步骤，完整练习还需检查其他字段、缺列和业务约束。不要用 `except Exception: pass`吞掉一切异常；那会把变量拼错等程序错误隐藏成“清洗完成”。

with负责在离开代码块时关闭文件，csv模块处理CSV的引号等语法；简单split(',')不足以正确读取任意CSV。

### 3. 对账证明处理没有偷偷丢数据

保留、拒绝、重复三类互斥，并记录源行号。验证输入总行数等于三者之和；再核对保留id、全部金额、paid金额和各用户金额。只核对行数不够，错误的金额仍可能保持相同行数。

输出保持确定的id排序，方便与SQL结果比较。练习可分两次完成：先正确解析并记录拒绝，再处理重复、冲突与统计。
