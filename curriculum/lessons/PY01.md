## 讲解与例题


### 1. 从输入到输出跟踪程序

函数把输入变成输出。先写输入类型、输出含义和边界，再写实现。下面例子不是把所有值相加，而是只累加paid订单：

```python
def paid_total(rows):
    total = 0
    for row in rows:
        if row['status'] == 'paid':
            total += row['amount']
    return total
```

rows是list，每个row是dict；`row['status']`按键取值。return放在循环外，才能处理全部订单。共用数据中结果250；空列表结果0。

### 2. 容器对应什么需要

list保存有序的一组对象；dict把键映射到值，适合按用户id累计；set表示唯一元素集合；tuple保存固定位置的一组值。选择依据是需要保序、索引、去重还是按键查询，而不是随意换一种写法。

```python
totals = {}
for row in rows:
    uid = row['user_id']
    totals[uid] = totals.get(uid, 0) + row['amount']
```

得到 `{1:400,2:50,4:0}`。这里缺用户3，因为输入只有订单。若需求包括所有用户，需要先用用户表初始化0。这与SQL LEFT JOIN中的结果粒度问题一致。

### 3. 不把字符串当数字

从CSV读取的'100'通常仍是字符串。`'100'+'50'`得到'10050'，必须明确解析成数值。原始数据、解析结果和拒绝原因分开记录，不要为了能运行而默默丢行。
