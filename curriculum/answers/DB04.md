# DB04｜答案与判分要点

先完成[本节练习](../lessons/DB04.md)。答案供核对，不代表唯一正确写法。


E1：INNER 5行、LEFT 6行、CROSS 4×5=20行。CROSS列举任意用户和任意订单组合，不表示实际所属。

```sql
-- E2: 只有用户3；用户4有cancelled订单。
SELECT u.id FROM users u LEFT JOIN orders o ON o.user_id=u.id WHERE o.id IS NULL;
-- E3: (1,2,200),(2,1,50),(3,0,0),(4,0,0)
SELECT u.id,COUNT(o.id),COALESCE(SUM(o.amount),0)
FROM users u LEFT JOIN orders o ON o.user_id=u.id AND o.status='paid'
GROUP BY u.id ORDER BY u.id;
```

E4：只有用户2变成2笔、125总额，其余不变。
必须能解释COUNT(*)的陷阱与ON/WHERE区别，不能只提交正确SQL。
