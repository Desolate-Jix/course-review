# DB02｜答案与判分要点

先完成[本节练习](../lessons/DB02.md)。答案供核对，不代表唯一正确写法。


```sql
-- E1: (101,100),(105,100),(103,50)
SELECT id,amount FROM orders WHERE status='paid' ORDER BY amount DESC,id;
-- E2: 2,3
SELECT id FROM users WHERE city <> 'Auckland' OR city IS NULL ORDER BY id;
-- E3: 原查询4行，去重3行；失去两个小王分别是谁的信息。
-- E4 AND: 101,105；OR: 101,102,103,105。
```

关键：不能用 `city = NULL`，不能靠默认排序解释结果。


看过答案的题记为“有提示”；隔日换数据独立重做，再决定是否达到B。
