# DB03｜答案与判分要点

先完成[本节练习](../lessons/DB03.md)。答案供核对，不代表唯一正确写法。


```sql
-- E1: cancelled 1/0; paid 3/250; pending 1/200
SELECT status,COUNT(*),SUM(amount) FROM orders GROUP BY status ORDER BY status;
-- E2: 用户1，2笔，总额200
SELECT user_id,COUNT(*),SUM(amount) FROM orders
WHERE status='paid' GROUP BY user_id HAVING COUNT(*)>=2;
```

E3：按常量分组形成一组；`WHERE user_id=1 GROUP BY user_id`形成一组；`GROUP BY user_id HAVING COUNT(*)>=2`只保留一组。应分别指出在哪个步骤减少了组。

E4：4、3、3。应能解释每个COUNT的统计对象。


看过答案的题记为“有提示”；隔日换数据独立重做，再决定是否达到B。
