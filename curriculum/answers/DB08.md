# DB08｜答案与判分要点

先完成[本节练习](../lessons/DB08.md)。答案供核对，不代表唯一正确写法。


1. 回滚100/100，提交80/120，总额200。必须用SELECT实测。
2. WHERE未匹配可能更新0行，需校验受影响行数、约束及事务内业务条件，不满足则回滚；并发下还需合适锁/隔离策略。
3. 初始50、B提交75。Read Committed的A可读50再75；Repeatable Read中A两次均50。第一条读需在B提交前发生，最后恢复数据。
4. 已成功提交的数据由数据库持久性机制保护；客户端超时只说明通信或等待结果不明确，重复提交需业务幂等/查询确认。

完整B标准要求事务与两会话实测。锁、死锁、WAL更深实现进入后续路线，不要求本节推导恢复算法。
