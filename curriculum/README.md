# 技术能力课程｜第一阶段

本课程配合 [learning-plan 每日安排](https://github.com/Desolate-Jix/learning-plan)。第一轮以数据库和查询为主线，Java算法恢复为辅，Python用于数据处理；正式起点2026-09-29，2026-09-26可提前热身。10/28是复盘点，不是强制学完截止。

目标：能够解释机制、独立实现、处理边界、用证据验证，并向面试官讲清楚。已做24道Java题的历史保留，先诊断再补学。

**新增：[面试八股总目录](interview/README.md)**。题量不设上限，按[覆盖地图](interview/COVERAGE.md)补齐机制、边界与实作；讲义中的两条入口示例不限制完整题卡范围。

## 怎样使用每一课

1. 核对先修；能独立通过先修验收就跳过重复讲解，不强制从零抄课件。
2. 阅读讲解，跟随例题手算，记录为什么每一步成立。
3. 关闭例题做独立练习，先写自己的结果再看答案。
4. 在课堂口述时段练一题八股和追问，再检查本节验收条件与反例；按 [掌握标准](ASSESSMENT.md)登记。
5. 在学习仓库记录实际日期、证据和复习到期时间。日历不会自动把你标成已完成。

每课都有先修、解释与例题、独立练习、答案和验收。首次学习可拆成两天；不会时先讲解和引导，不连续抛题代替教学。
