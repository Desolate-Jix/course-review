Property Graph Model - Formal Definition
Notation
We assume the following sets are pairwise disjoint.
O is a set of objects,
L be a finite set of labels,
K is a set of property keys, and
N is a set of values.
Definition (Property graph)
A structure (V, E, ⌘, ￾, ⌫) where
V ✓ O is a finite set of objects, called vertices,
E ✓ O is a finite set of objects, called edges,
⌘ : E ! V ⇥ V is a function assigning to each edge an ordered pair of vertices,
￾ : V [ E ! P(L) is a function assigning to each object a finite set of labels, and
⌫ :(V [ E) ⇥ K ! N is a partial function assigning values for properties to
objects, such that the set of domain values where ⌫ is defined is finite.
````
