Token-based
 In the token-based algorithms, a unique token is shared 
among the tasks. 
 A task is allowed to access the shared resource if it holds 
the token.
 In Raymond’s algorithm, in order to locate the token, a 
spanning tree is constructed. 
 Each task is a node in the tree
 Each task has a variable, holder, that records the identity of 
one of its neighbours in the spanning tree which might hold the 
token
 If a task needs to access the shared resource, the task sends a 
token_request message to the neighbour that might hold the 
token
 When receive a token_request message, if a task does not have 
the token, it forwards the request to its neighbour that might 
hold the token. This process continues until the token is located. 
The located token is sent to the neighbour that sent the 
token_request message.
