````text
Index on Two Elements
↭ Definition:
↭ When an index is created on two elements (composite key), we
assume a lexicographic sort on these two columns.
↭ Example:
↭ Consider a table Orders with columns CustomerID and
OrderDate.
↭ A clustered index on (CustomerID, OrderDate) written as
Ic (CustomerID, OrderDate) will sort the data first by
CustomerID and then by OrderDate within each CustomerID.
↭ Benefits:
↭ E!cient range queries on the composite key.
↭ Improved performance for queries that filter by these columns.
↭ Considerations:
↭ Only one clustered index can be created per table.
↭ The choice of columns for the clustered index should be based
on the most frequently used queries.
````
