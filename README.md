## 后续使用

先按岗位阅读优先级，再打开课程大纲中的代表资料。后续新增八股卡片时，应记录“问题、解释、反例／边界、原始来源、实践题”；项目经历则另记个人贡献与实际结果。

材料中的个人批注、演讲稿、旧课件和 OCR 结果均不自动等于准确的技术结论。此轮未逐题校正原笔记，也未验证其中的业务数据或历史案例数字。

本仓库用于个人复习，不对原课件授予再分发许可。维护日期：2026-09-23。
