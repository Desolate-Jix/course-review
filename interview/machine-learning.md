# 机器学习与评估

来源：[INFOSYS 722](../courses/INFOSYS722/README.md)。DS／AI 优先级：高。

主线：业务问题 → 数据与标签 → 处理／探索 → 模型 → 验证与指标 → 使用与反馈。

候选问题：

1. 回归、分类、聚类和关联分别适合什么问题？
2. 训练、验证、测试的职责如何区分？
3. 过拟合与欠拟合如何体现？正则化和交叉验证分别解决什么？
4. 朴素贝叶斯、kNN、决策树、SVM、回归如何选择？
5. 为什么只看准确率可能不够？Precision／Recall、ROC／AUC 分别衡量什么？
6. K-means 的 k 如何选择、聚类结果如何评价？
7. 关联规则的 support 和 confidence 如何解释？

数据泄漏、时间切分等可作为后续实践检查项，但不要把扩展练习误写成已确认的完整课程章节。
