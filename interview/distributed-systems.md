# 并发与分布式系统

来源：[COMPSCI 711](../courses/COMPSCI711/README.md)。开发／后端优先级：高。

范围：进程／线程、monitor、条件变量、逻辑时钟、向量时钟、多播、互斥、死锁、snapshot、Paxos、CAP、缓存。

候选问题：

1. 互斥和条件同步分别解决什么？
2. Lamport 时间戳能否充分判断因果关系？向量时钟多保存了什么？
3. FIFO、因果序、全序的要求分别是什么？
4. 如何在没有全局时钟时取得一致快照？
5. 安全性、活性、公平性如何分别被破坏？
6. 网络分区、共识和副本一致性有什么关系？
7. CPU cache、数据库 buffer pool、Web cache 的目标和失效机制有何不同？

用时序图与失败场景解释；特定算法的长证明放在基本概念之后。
