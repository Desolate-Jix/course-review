# 检索、数据摘要与推荐

来源：[COMPSCI 753](../courses/COMPSCI753/README.md)、[COMPSCI 752](../courses/COMPSCI752/README.md)。检索／推荐／数据算法岗位优先级：高。

候选问题：

1. Jaccard、MinHash、LSH 三者如何串起来？
2. LSH 与通用哈希追求的碰撞特性有什么区别？
3. banding 如何改变候选量与误报／漏报？
4. reservoir sampling 为什么能做固定大小的流式抽样？
5. Bloom filter 与 Count-Min Sketch 回答的是同一问题吗？
6. Misra–Gries、Count-Min 和 Count Sketch 如何更新、查询、产生误差？
7. 协同过滤与潜因子模型如何处理评分矩阵？
8. 冷启动、稀疏性、正则化和偏置项分别解决什么？
9. 为什么 RMSE 好不必然等于 Top-N 推荐体验好？

进阶专题：PageRank、社区检测、影响力最大化、上下文推荐、张量分解、Factorization Machines。按岗位选择，不一次背完。
