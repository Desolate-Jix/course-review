# 数据库内部机制

来源：[COMPSCI 751](../courses/COMPSCI751/README.md)。优先级：高。

主线：存储与 buffer pool → B+ 树／哈希／LSM → 执行计划与代价 → ACID／隔离／锁 → WAL 与恢复。

候选问题：

1. 索引何时减少 I/O，何时反而带来成本？
2. B+ 树、哈希、LSM 的查询与更新取舍是什么？
3. 选择率与连接顺序如何影响中间结果？
4. 脏读、不可重复读、幻读如何通过交错操作发生？
5. 锁、可串行化和死锁分别在讨论什么？
6. 为什么 WAL 需要先写日志？undo／redo 与 steal／no-force 有何联系？

与 711 合并时，区分事务隔离与分布式副本一致性；不要把通用课件机制直接等同于某款数据库的具体实现。
