# 数据工程与图数据

来源：[COMPSCI 752](../courses/COMPSCI752/README.md)、[COMPSCI 751](../courses/COMPSCI751/README.md)。优先级：数据工程／AI 数据层高。

范围：数据采集／清洗／近重复、XML、RDF／Property Graph、Cypher／SPARQL、知识图谱、MapReduce／HDFS、流处理、差分隐私。

候选问题：

1. 哪类关系适合图模型？RDF 和 Property Graph 如何表达同一事实？
2. Map、Shuffle、Reduce 各自接收和产生什么？
3. 为何数据移动和分组是分布式处理的重要成本？
4. 怎样表示文档、识别近重复或做 similarity join？
5. 只允许单遍、有限内存时，可以保留什么摘要？
6. 匿名化为何不能自动消除信息泄漏？差分隐私讨论的对象是什么？

本轮课件支持知识图谱基础，但不能自动视为完整 GraphRAG／RAG 项目的实现证据。
