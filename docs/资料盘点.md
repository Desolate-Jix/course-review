# 资料盘点、归属与缺口

## 扫描与阅读方法

本地来源为用户指定的 `E:\学习\Notability`。递归枚举全部目录，共 **346 个文件**：263 个 PDF、80 个 `.note`、3 个 DOCX；没有找到独立 `.ppt`／`.pptx` 文件，许多幻灯片以 PDF 或笔记附件保存。263 个 PDF 合计 **6,389 页**，该数包含相近版本和最终排除范围，不表示 6,389 页都做了人工逐页细读。

对全部 PDF 扫描文字层并生成页级索引；对全部 `.note` 检查包结构和同名 PDF 配对；9 个没有同名 PDF 的原生笔记也检查了内嵌 PDF／图片，其中 727 的 2 个在后续范围收窄后排除。3 个 Word 文档读取正文。对图片型／低文字量资料补充本地 OCR，并目视核验部分代表页。阅读重点是课程身份、章节／模块、考前复习结构和项目主题，不逐页详细总结，也不逐句验证手写答案。

**OCR 限制：**手写公式、中文批注、照片透视、PDF 字体编码可能使抽取不完整。大纲优先依据清晰的课件标题和正文、反复出现的模块及代表页；可疑细节不补造。原生 `.note` 与同名 PDF 作为配对阅读入口，不保证两者编辑状态完全一致。

## 重复与版本

276 个纳入文件的 SHA-256 均不同，没有发现字节完全相同的副本。多份文件具有相同或近似的正文、页数和文件名，但可能存在手写批注、页面、导出元数据等差异。此次没有删除、覆盖或只保留“看起来最新”的版本。

原文件级来源与校验值见 [materials.json](../metadata/materials.json)。人读索引见[原始文件索引](原始文件索引.md)。F 编号来自全目录初次扫描，因此最终编号有间断。
