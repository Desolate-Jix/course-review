## 文件位置与阅读方式

每门课程的 `extracted/README.md` 提供原件与文本副本的对照索引：

```text
courses/<课程代码>/source/<原相对路径>.pdf
  → courses/<课程代码>/extracted/source/<原相对路径>.pdf.md

courses/<课程代码>/notes/original/<原相对路径>.pdf
  → courses/<课程代码>/extracted/notes/<原相对路径>.pdf.md
```

保留原相对路径和 `.pdf.md` 后缀，避免同名文件、不同导出版本互相覆盖。每份文本开头记录实际原文件路径、可点击链接、文件 ID、SHA-256 和总页数。每页使用 `PDF 第 N 页` 标题，并提供 `#page=N` 原页链接；原幻灯片自身的页码／slide 编号仍留在提取文字中，两者可能不同。GitHub PDF 预览不一定响应页码锚点，可下载后在 PDF 阅读器跳转。

这是逐页全文副本，不替代现有课程大纲：

- **原始文字层**：逐页保留 PDFium 提取的全部文字，仅统一换行、删除 NUL 控制字符与页首尾空白；不改写、不压缩、不删除重复动画页。
- **坐标排版辅助视图**：对适合的文字层使用 pypdf layout 模式恢复相对列位置与缩进，以辅助阅读代码、公式和表格；原文字层另行完整保留。疑似乱码和部分扫描笔记不生成这一视图。
- **图片文字 OCR**：本机 Windows OCR；本批文件每页均满足图片占比／文字不足／可疑编码条件，因此 6,124 页全部做 OCR。使用英文识别，检测到中文或稀疏笔记页时另补中文识别；两种结果分别标注，不混成未经校正的“标准答案”。
- **图表辅助说明**：对人工看图核对的关键页面，用短文补充节点、箭头、矩阵、流程和曲线含义，明确与原文区分；描述保存在 [diagram-descriptions.json](../metadata/diagram-descriptions.json)。其他图形保留标签与返回原页提示。

## 使用边界

文字层／OCR 可能重复；扫描页、手写字、表格列关系、数学上下标与特殊符号可能识别错误。公式尽量保留原字符及排版，并未统一重写为 LaTeX；代码也未作为可执行程序校正。图表说明覆盖选定的关键页面，并非所有图片的人工逐一转录；复杂图形仍需对照原 PDF。原课件中的历史信息、个人批注和可能错误均照录，提取不代表技术正确性背书。

`.note` 和 DOCX 原始笔记本轮保持原样，未伪装成 PDF 文本输出；可用的 PDF 导出已纳入。DIGIHLTH703 与 ACADINTA01 没有确认的原课件，因此没有生成空内容副本。727、720、ELA 仍在范围外。

## 复现与校验

依赖 Python 的 `pypdfium2`、`pypdf` 与 `Pillow`，以及 Windows OCR 的 en-US / zh-Hans-CN 语言组件。所有识别在本机执行，无需上传到第三方 OCR 服务。中间渲染图、缓存和 OCR 结果位于被 Git 忽略的 `tmp/course_extract/`。

```powershell
python scripts/extract_course_text.py prepare
powershell.exe -NoProfile -File scripts/ocr_course_pages.ps1
python scripts/extract_course_text.py build
python scripts/verify_archive.py
python scripts/verify_extractions.py
```

`prepare` 与 OCR 支持当前批次断点续跑；如果新增或替换了原文件，需要先更新材料清单并清理对应文件 ID 的旧缓存，避免复用旧识别结果。`build` 重新生成文本与索引。

[extractions.json](../metadata/extractions.json) 记录逐文件来源、输出路径、页数和提取统计。校验脚本直接重读原 PDF，核对覆盖范围、完整连续物理页码、全文是否写入、图表说明与源文件哈希；`verify_archive.py` 另检查全部 276 个原始文件的哈希和 Markdown 链接。

## 本批校验结果

- 224 份副本覆盖 6,124 个连续物理页；129 份 source 课件全部有对应输出。

- 全部 276 个原始文件 SHA-256 与原清单一致。
